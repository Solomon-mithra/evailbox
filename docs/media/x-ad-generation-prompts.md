# evailbox X ad generation prompts

Created with the built-in OpenAI image generation tool on 2026-09-26. Each variant was generated separately. These prompts are creative direction; the exported images are the delivered artwork.

Source artwork: `public/icon-512.png`, `public/brands/gmail.svg`, and `public/brands/outlook.svg`. The SVGs were rasterized as temporary generation inputs. Logos within the generated compositions are AI-rendered interpretations of those inputs.

Set the brand name exactly "evailbox" in lowercase, spelled e-v-a-i-l-b-o-x. Design legibly at phone-feed size with generous outer margins. The user post paired with it says: "i needed my EMAILS to be sorted by my rules. Is that too much to ask!?" The artwork is its visual companion, not a screenshot of the post.

"Your inbox."
"Your rules."
